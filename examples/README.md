# 任务卡模板

```
任务 ID: T<序号>-<短描述>
标题: <一句话标题>
执行端: <agent-key>
模型: <model-name>
复杂度: L1|L2|L3|L4
```

## 验收标准

<明确、可检验的完成条件。例如："产物文件 output/result.txt 存在且非空，且通过 pytest 测试。">

## 产物

<预期产出的文件路径或交付物。例如："output/result.txt">

## 证据

<验证产物正确性的证据。例如："git diff --stat 显示改动，pytest 全绿">

## 任务描述

<详细描述任务背景、要求、约束。>
```

## contract.json 示例

```json
{
  "task_id": "T01-hello",
  "acceptance": "产物文件 output/result.txt 存在且非空",
  "output": "output/result.txt",
  "evidence": "pytest tests/ 全绿",
  "complexity": "L2",
  "required_caps": ["your-agent"],
  "work_key": "project:deliverable",
  "fingerprint": "<auto-generated>"
}
```

## 完整生命周期示例

```bash
# 1. 创建
python3 board/board-task-create.py \
  --id T01-demo \
  --title "示例：生成报告" \
  --work-key analytics \
  --acceptance "report.md 存在且 >100 字" \
  --output "report.md" \
  --evidence "wc -w report.md > 100" \
  --complexity L2 \
  --created-by trae

# 2. 认领（某个 agent）
python3 board/board-task-transition.py --task T01-demo --action claim --agent workbuddy

# 3. 执行完毕，提交
python3 board/board-task-transition.py --task T01-demo --action submit \
  --agent workbuddy --request-id req-001

# 4. 另一个 agent 验收
python3 board/board-task-transition.py --task T01-demo --action review \
  --agent codex --verdict PASS --request-id req-002

# 5. 审计确认
python3 board/board-audit.py

# 6. 归档
python3 board/board-task-transition.py --task T01-demo --action archive \
  --agent codex --request-id req-003
```
